# 规则

规则层产生语义事件，表现层负责 Tween、粒子和声音。服务器持有唯一比赛 RNG、EntityId、Turn、ActionId、GameStateVersion。

目标包括换牌、30 张卡组、疲劳、10 手牌/7 随从、法力、武器、11 职业技能、关键字、战吼、亡语、奥秘、光环与同时死亡。实际支持以测试和状态清单为准。

`game/history_fixes.py` 在注册阶段补正固定上游脚本，不改参考仓库。通过继承原脚本类保留 Hand/Cost/Play 等其他属性，避免仅补目标规则时丢失实际效果。死亡计数使用玩家当回合计数；眼棱按本方左右端判断减费；法力燃烧在对方下一回合锁定两点临时法力并销毁附魔，多个副本可叠加。基础逐牌执行矩阵和专项位于 `tests/test_history_cards.py`，489 张可执行不等于全部边界已核验。
