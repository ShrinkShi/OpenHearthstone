# 视觉效果逆向标准工作流

适用于既定卡或有界效果；来源复原、行为复原、视觉准确度三栏分开记录。执行者先完成可重复交付，再交给不同上下文的 Verification。局部测试不能越级替代整效果验收。TASK-0004 的实际演练和限制见 [TASK4_EVIDENCE](TASK4_EVIDENCE.md)。

1. **限定身份和证据。** 读取 Task/数据库/实际注册表，固定 CardID、原 Prefab、CAB/PathID、原bundle与缓存SHA。核对名称/类型，保留误标历史，不把相近名字或同Shader当同一效果。官方媒体记录来源、产品版本、原始文件SHA。文件缺失先搜已关联范围；源安装只读、禁止把原DLL执行冒充自主实现。
2. **先判定可比。** 清点官方素材；区分官方、内部基线、离屏诊断、工具/资源图。官方与复刻须记录分辨率/机位/投影、source/targets/状态/分支/视角、色彩/光照/后处理/声音环境。无合格官方序列→保留可独立做的单侧序列、索引和Shader局部证据，缺项Unknown，整体BLOCKED。条件不同→先解释遮挡/裁切/色彩等差异，建立显式配准或补资料；不直接算“还原百分比”。
3. **证实当前完整控制链。** 从真实输入/创建/初始化/SourceAuto/Targets/Birth→运动→Arrival→Hit→Death/None/销毁/任务同步记录实际事件。证明独立克隆、资源所有权和外部服务契约。出现缺服务/错误/取消/晚回调→停止把空帧当正常视觉，按最早不确定阶段复现；有界缺陷另立Task，不用延长路径、猜FSM时间或占位图遮蔽。
4. **固定重放条件。** 固定本项目输入文件及哈希、构建/源码SHA、相机/RT/色彩空间、随机流/种子与显式时钟。源全局随机未知就标Unknown，不能宣称同seed。保留绝对秒与事件相位；Birth/Early/Mid/Arrival/Hit/Death的触发定义写清，Death激活与None回收分开。相同时间的事件依真实顺序保存，不平移掩饰节奏差异。背景/合成、Glow和音频是否真实运行逐一写明。
5. **按单一变体追Shader。** 原材质→Shader→SubShader/Pass/Keyword→编译stage/参数/采样器/常量offset→原渲染状态→等价公式→接线→实际GPU读回。直接恢复保存原字节/状态哈希；行为重建说明逐指令依据；推测单列待证。检查纹理槽/ST、UV/空间、mask/noise/distortion/dissolve、光照/顶点/屏幕输入、Blend/Alpha/深度/Cull/Stencil/Queue。未使用/未知与已证无输入不同。原纹理raw、mip、sampler、色彩空间与动态RT不能用外观相近PNG替代。
6. **数值与真实材质分别验证。** 浮点GPU样本覆盖有效域/边界/忽略输入/HDR/负值/实际混合，给实际/期望/误差/阈值；再核实际Prefab使用的材质、纹理和状态。编译/空帧/阈值失败→保留失败日志，回到stage或接线，不只放宽阈值。单公式通过而真实场景失败→沿捕获/排序/合成/动态输入查，不能升级整卡。PNG会裁剪HDR，浮点结论要读回数据。
7. **生成匹配关键帧和分项结果。** 官方与复刻分别保存索引/hash和时标，按真实事件对齐，兼看绝对时间及相位。位置/轨迹/尺度/旋转、持续时间、RGB/亮度、Alpha、粒子数量/分布、Trail形态/衰减、声音内容/起点/音量/混音分列。只有相机/状态/色彩可比才做像素差，参数遥测和音轨需要对应来源；无法测得的差异、阈值和等级写Unknown。像素相似不能证明生命周期/音频/隐藏分支。保留多背景C/K检验，透明度不能仅从黑底RGB推断。
8. **复现、审阅和决定。** 至少两个新进程验证单侧重放稳定性，检查真实退出码/异常与拥有资源释放。contact sheet清楚标出来源和未覆盖范围。符合全部目标→READY_FOR_REVIEW，固定中文实现提交，独立V审核来源、反例、图像和限制；验证通过才由总控登记。只有程序自动部分完整且合格官方参考都已给出、仅主观外观待人判断→AWAITING_HUMAN_REVIEW。缺原资料仍BLOCKED。V5需同条件逐帧证据，V6还需完整自主行为/效果；不取分项最大值或单一相似度代替整体。

成功分支的最低交付：可重放命令和固定提交、原始来源/版本/hash、输入/机位/时钟/种子、双方帧索引与contact sheet、分项机器结果与解释、Shader编译来源到实际GPU的审计、异常/清理证据和独立验证。失败或阻塞分支也交付已完成部分、精确缺字段/范围、真实未跑项、最小补充资料与继续入口，不发布虚假的通过结论。
